Screen Monitor 사용 가이드

네트워크의 여러 PC 주모니터 화면을 한곳에 모아 CCTV처럼 모니터링하는 방법을 설명합니다.
관리자(서버 운영자)와 클라이언트 PC 사용자 모두를 위한 문서입니다. 이 페이지는 서버의 /guide 주소에서 로그인 없이 볼 수 있습니다.

1개요

Screen Monitor는 세 부분으로 구성됩니다.

① 서버 (관리자 PC 1대)화면을 받아 모으고 관리자 웹 페이지를 제공합니다. server/app.py
② 클라이언트 앱 (모니터링 대상 PC)그 PC의 주모니터 화면을 서버로 보냅니다. ScreenMonitorClient.exe
③ 관리자 웹 (브라우저)로그인하면 등록된 모든 PC 화면이 CCTV 월로 보입니다.
  • 서버는 관리자가 등록한 IP의 화면만 받습니다. 등록되지 않은 PC가 접속하면 거부하고 등록 대기 목록에 표시합니다.
  • 클라이언트 앱은 주모니터 화면만 보냅니다. 앱 창 제목에 ● … 공유 중이 표시되어, PC 사용자도 공유 중임을 항상 알 수 있습니다.
  • 평소에는 저화질·저프레임(최대 1fps)으로, 관리자가 특정 PC를 크게 열면 그 PC만 고화질·고프레임(약 8fps)으로 전환됩니다. PC 부하를 더 줄이려면 주기 캡처 모드를 사용하세요.

2빠른 시작

  1. 서버 실행 — 관리자 PC에서 server\run_server.bat를 실행합니다. 콘솔에 관리자 비밀번호와 클라이언트 토큰이 표시됩니다.
  2. 로그인 — 브라우저에서 http://서버IP:8000에 접속해 admin 계정으로 로그인하고, 오른쪽 위 자물쇠 아이콘으로 비밀번호를 바꿉니다.
  3. PC 등록 — PC 관리에서 모니터링할 PC의 IP와 이름을 등록합니다.
  4. 클라이언트 실행 — 각 PC에서 ScreenMonitorClient.exe를 실행하고 서버 주소·접속 토큰을 입력한 뒤 공유 시작을 누릅니다.
  5. 모니터링 — 관리자 웹에 화면이 나타납니다. 타일을 클릭하면 크게 볼 수 있습니다.

3서버 설치·실행 (관리자 PC)

준비물

  • Windows PC 1대 (항상 켜져 있는 PC 권장)
  • Python 3.10 이상 — 설치 시 "Add python.exe to PATH"를 체크하세요.

실행

  1. server 폴더의 run_server.bat를 더블클릭합니다. 필요한 패키지를 자동 설치한 뒤 서버가 시작됩니다.
  2. 처음 실행하면 콘솔에 아래와 같은 정보가 표시됩니다. 
    ============================================================
 최초 관리자 계정이 생성되었습니다
   아이디   : admin
   비밀번호 : (무작위 비밀번호)
============================================================
 Screen Monitor 서버
   관리자 웹   : http://192.168.0.10:8000
   클라이언트 토큰 : (접속 토큰)
    초기 비밀번호는 server\data\initial_admin_password.txt에도 저장되며, 웹에서 비밀번호를 바꾸면 이 파일은 자동으로 삭제됩니다.
  3. Windows 방화벽에서 TCP 8000 포트 인바운드를 허용합니다. 처음 실행할 때 나오는 방화벽 알림에서 개인 네트워크 허용을 눌러도 됩니다.
주의 콘솔 창을 닫으면 서버가 종료됩니다. 서버가 꺼져 있으면 클라이언트는 자동으로 재접속을 시도하며 기다립니다.

자주 쓰는 관리 명령

server 폴더에서 실행합니다.

할 일명령
비밀번호 재설정 (분실 시)python app.py set-password admin 새비밀번호
관리자 계정 추가python app.py set-password 아이디 비밀번호
클라이언트 토큰 확인python app.py show-token
다른 포트로 실행python app.py --port 9000

4PC 등록 (관리자 웹)

오른쪽 위 PC 관리 버튼을 누르면 관리 패널이 열립니다.

방법 A — IP를 직접 등록

  1. PC 등록에 IP 주소(예: 192.168.0.21)와 표시 이름(예: 1번 PC)을 입력합니다.
  2. 화면 전송 방식을 고릅니다. 기본은 실시간 스트리밍입니다.
  3. 등록을 누릅니다. 그 PC에서 클라이언트 앱이 실행 중이면 약 10초 안에 화면이 나타납니다.
팁 PC의 IP는 그 PC에서 ipconfig 명령으로 확인하거나, 클라이언트 앱 아래쪽의 내 IP 표시를 보면 됩니다.

방법 B — 등록 대기 목록에서 등록 (IP를 몰라도 됨)

클라이언트 앱을 먼저 실행하면, 등록되지 않은 PC는 등록 대기 목록에 PC 이름과 함께 나타나고 PC 관리 버튼에 빨간 숫자가 붙습니다. 목록의 등록을 누르면 IP와 이름이 자동으로 입력되며, 확인 후 등록하면 됩니다.

수정·삭제

  • 수정 — 표시 이름과 화면 전송 방식을 바꿀 수 있습니다. "이 전송 방식을 등록된 모든 PC에 적용"을 체크하면 전체 PC에 한 번에 적용됩니다.
  • 삭제 — 그 PC의 연결이 즉시 끊기고 화면 수집이 중단됩니다. 클라이언트 앱에는 "등록 대기"가 표시됩니다.

클라이언트에 알려줄 정보

관리 패널 맨 아래 클라이언트 앱 연결 정보에 서버 주소와 접속 토큰이 있습니다. 복사 버튼으로 복사해 각 PC 사용자에게 전달하세요.

5클라이언트 앱 (모니터링 대상 PC)

설치·실행

  1. ScreenMonitorClient.exe를 PC의 원하는 폴더(예: C:\ScreenMonitor)에 복사합니다. 별도 설치나 Python이 필요 없습니다.
  2. 실행한 뒤 서버 주소(예: http://192.168.0.10:8000)와 접속 토큰을 입력합니다.
  3. 공유 시작을 누릅니다. 상태가 화면 공유 중으로 바뀌면 완료입니다.

옵션

옵션설명
프로그램 실행 시 자동으로 공유 시작앱을 켜면 버튼을 누르지 않아도 바로 공유합니다.
Windows 로그인 시 자동 실행PC를 켜고 로그인하면 앱이 최소화 상태로 자동 실행되어 공유를 시작합니다.
저부하 모드실시간 대신 정해진 주기(5초~10분)마다 한 장만 캡처합니다. 오래된 PC나 성능이 중요한 작업 PC에 사용하세요. 자세히

입력한 서버 주소·토큰·옵션은 자동 저장됩니다(%APPDATA%\ScreenMonitorClient\config.json). 창을 닫으면 [예] 공유 중지 후 종료 / [아니오] 최소화하고 계속 공유 중에서 고를 수 있습니다.

등록 대기서버에 이 PC의 IP가 등록되지 않았습니다. 표시된 IP를 관리자에게 알려 주세요. 등록되면 10초 안에 자동으로 공유가 시작됩니다.

여러 PC에 일괄 배포 (명령줄 옵션)

바로가기나 배포 스크립트에서 아래처럼 실행하면 입력 없이 바로 공유를 시작합니다.

ScreenMonitorClient.exe --server http://192.168.0.10:8000 --token 접속토큰 --connect --minimized
ScreenMonitorClient.exe --low-load 30     (저부하 모드 30초 주기로 켜기, 0 = 끄기)
exe가 실행되지 않을 때 서명되지 않은 exe는 Windows의 스마트 앱 컨트롤 / 애플리케이션 제어 정책이나 SmartScreen에 의해 차단될 수 있습니다. SmartScreen 경고는 추가 정보 → 실행으로 실행할 수 있지만, 정책 차단은 조직 관리자가 정책에서 허용하거나 코드 서명 인증서로 서명해야 합니다.

슬라이드 쇼

상단의 슬라이드를 누르면 공유된 화면을 한 대씩 화면 가득 보여 주고, 정해진 시간마다 다음 PC로 자동으로 넘어갑니다. 상황실 모니터처럼 한 화면을 돌려 가며 보여 줄 때 좋습니다. 마지막으로 고른 보기 방식과 옵션은 브라우저에 기억됩니다.

버튼 / 키기능

전환 간격한 PC를 보여 주는 시간 (5초 ~ 5분). 화면 아래 파란 막대가 남은 시간을 보여 줍니다.

PC 접속·연결 끊김·미등록 PC 접속 시도는 오른쪽 아래 알림으로 표시됩니다.

7부하 줄이기 — 화면 전송 방식

PC마다 화면을 보내는 방식을 고를 수 있습니다. 주기 캡처는 화면을 계속 스트리밍하지 않고 정해진 주기마다 한 장만 찍어서 보내므로, 그 사이에는 캡처·압축을 전혀 하지 않아 PC의 CPU 사용량과 네트워크 사용량이 크게 줄어듭니다.

방식동작PC 부하네트워크 (PC 1대)적합한 경우
실시간 스트리밍 (기본)매초 화면을 확인해 바뀐 경우 전송 (최대 1fps, 변화 없으면 10초마다 1장)낮음
측정: 코어 1개의 약 5%		약 0.1~0.5 Mbps실시간 확인이 필요한 PC
주기 캡처 (5초~10분)N초마다 한 장만 캡처해 전송매우 낮음
측정: 10초 주기 약 0.6%		30초 주기 약 0.03~0.08 MbpsPC가 많을 때, 오래된 PC, 네트워크가 느린 곳
확대 보기 중고화질 약 8fps 스트리밍보통약 5~8 Mbps관리자가 한 PC를 자세히 볼 때만

부하 수치는 3440×1440 주모니터 PC에서 측정한 값이며, 화면 해상도와 PC 성능에 따라 다릅니다.

관리자가 설정하기 (PC별 / 전체)

  1. PC 관리 → 해당 PC의 수정을 누릅니다. (새로 등록할 때는 등록 폼에서 바로 고를 수 있습니다.)
  2. 화면 전송 방식에서 실시간 스트리밍 또는 5초 / 10초 / 30초 / 1분 / 5분 / 10분마다 캡처를 선택합니다.
  3. 필요하면 옵션을 정하고 저장을 누릅니다. 접속 중인 PC에는 즉시 적용됩니다.
    • 확대 보기를 열면 실시간으로 전환 (기본 켜짐) — 주기 캡처 PC라도 관리자가 크게 볼 때만 실시간으로 바꿉니다. 끄면 확대해도 주기를 유지하고, 열 때 최신 화면 한 장만 받습니다.
    • 이 전송 방식을 등록된 모든 PC에 적용 — 전체 PC를 한 번에 바꿉니다.

PC 사용자가 직접 켜기 — 클라이언트 저부하 모드

클라이언트 앱의 "저부하 모드: 실시간 대신 [N] 마다 한 장만 캡처"를 체크하면, 관리자 설정과 관계없이 그 PC는 주기 캡처로 동작합니다. 공유 중에도 바로 적용됩니다.

  • 관리자 설정과 저부하 모드 중 더 긴 주기가 적용됩니다.
  • 저부하 모드에서는 관리자가 확대 보기를 해도 실시간으로 바뀌지 않습니다. (지금 캡처 요청은 최소 2초 간격으로 응답)
  • 앱의 프로세스 우선순위를 보통 미만으로 낮춰, 사용자의 작업이 항상 먼저 처리되게 합니다.
  • 관리자 웹에는 PC 목록에 PC 저부하 표시가 붙고, 타일에 실제 적용 중인 주기가 나타납니다.

권장 설정

상황권장
PC 20대 이하, 사내 유선 네트워크전체 실시간 (기본값)
PC 수십 대 이상 / 무선·원격지 네트워크전체 10~30초 주기 + 확대 시 실시간 ON

근무 기록용 화면 보관 정도면 충분1~5분 주기 + 필요할 때 지금 캡처
참고 주기 캡처는 클라이언트 v1.1.0 이상에서 동작합니다. 이전 버전 클라이언트는 설정을 무시하고 계속 실시간으로 보내므로, 수정 창에 경고가 표시되면 새 exe로 교체하세요. (버전은 클라이언트 앱 오른쪽 아래에 표시)

주기 캡처 PC는 "응답 없음"(노란 점) 판정도 주기에 맞춰 늘어납니다. 예를 들어 1분 주기 PC는 약 75초 동안 새 화면이 없을 때 노란 점으로 바뀝니다.

8문제 해결

클라이언트가 "서버에 연결할 수 없습니다"라고 표시됩니다
  • 서버 콘솔 창이 실행 중인지 확인하세요.
  • 서버 주소가 맞는지 확인하세요. 클라이언트 PC 브라우저에서 http://서버IP:8000/guide가 열리면 주소와 네트워크는 정상입니다.
  • 열리지 않으면 서버 PC의 Windows 방화벽에서 TCP 8000 인바운드를 허용하세요.
클라이언트는 "화면 공유 중"인데 관리자 화면에 안 보입니다
  • 검색창에 글자가 남아 있지 않은지 확인하세요.
  • 공유기·VPN을 거치면 서버가 보는 IP가 PC의 IP와 다를 수 있습니다. 등록 대기 목록에 나타난 IP로 등록하세요.
계속 "등록 대기" 상태입니다

관리자 웹 PC 관리에서 앱에 표시된 IP를 등록하세요. 등록 후 10초 안에 자동으로 공유가 시작됩니다.

타일에 노란 점(응답 없음)이 표시됩니다

PC가 연결은 되어 있지만 새 화면이 오지 않는 상태입니다. 잠금 화면, 보안 데스크톱(UAC 창), 절전 모드에서는 화면을 캡처할 수 없습니다. 사용자가 다시 로그인하거나 화면이 켜지면 자동으로 재개됩니다.

엉뚱한 모니터가 보입니다

Windows 설정 → 시스템 → 디스플레이에서 "이 디스플레이를 주 모니터로 만들기"가 선택된 모니터가 공유됩니다. 주모니터를 바꾼 뒤에는 클라이언트 앱에서 공유 중지 → 공유 시작을 눌러 주세요.

관리자 비밀번호를 잊어버렸습니다

서버 PC의 server 폴더에서 python app.py set-password admin 새비밀번호를 실행하세요. 서버를 재시작할 필요는 없습니다.

"로그인 시도가 너무 많습니다"가 표시됩니다

5분 동안 5번 이상 틀리면 5분간 로그인이 제한됩니다. 잠시 후 다시 시도하세요.

서버를 재시작했더니 다시 로그인해야 합니다

정상 동작입니다. 로그인 정보는 서버 메모리에만 보관되며(12시간 유지), 등록한 PC 목록과 설정은 그대로 남아 있습니다. 클라이언트는 자동으로 다시 접속합니다.

네트워크가 느려졌습니다 / PC가 느려졌다는 의견이 있습니다

주기 캡처 모드로 바꾸세요. 확대 보기는 PC 1대당 5~8 Mbps를 사용하므로 필요할 때만 열고, 다 본 뒤에는 닫으세요.

9보안·관리

  • 최초 비밀번호는 반드시 변경하세요. 변경하면 initial_admin_password.txt가 자동 삭제됩니다.
  • 접속 토큰을 아는 사람만 클라이언트를 연결할 수 있고, 그중에서도 등록된 IP만 수집됩니다. 토큰은 외부에 공유하지 마세요.
  • 서버 PC에 공인 IP가 있다면 방화벽에서 8000 포트를 내부 네트워크 대역(예: 192.168.0.0/24)으로만 허용하세요.
  • 화면 이미지는 서버에 저장되지 않습니다. 각 PC의 마지막 화면 한 장만 메모리에 있다가 서버 종료 시 사라집니다. (스냅샷 버튼으로 저장한 파일은 관리자 PC에 남습니다.)
  • 화면 모니터링은 개인정보·근로 관련 법령과 사내 규정에 따라 대상자에게 고지·동의를 받은 뒤 사용하세요. 클라이언트 앱은 공유 중임을 창 제목과 상태로 항상 표시합니다.

데이터 위치 / 백업

파일내용

서버를 다른 PC로 옮길 때는 server\data 폴더를 통째로 복사하면 계정·PC 목록·토큰이 그대로 유지됩니다. 서버 IP가 바뀌면 각 클라이언트의 서버 주소를 새로 입력해야 합니다.

접속 토큰을 바꾸려면 서버를 끄고 config.json의 agent_token 값을 지운 뒤 다시 실행하면 새 토큰이 만들어집니다. (모든 클라이언트에 새 토큰을 입력해야 합니다.)
